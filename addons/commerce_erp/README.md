# Commerce ERP Starter

This installable Odoo module groups the standard applications and the project storefront for the initial connected commerce and ERP foundation:

- Website and eCommerce
- Sales
- Inventory
- Purchase with stock integration
- Accounting
- Commerce Storefront homepage

The bundle does not add product/customer data, tax rules, or payment-provider configuration. Those depend on the catalog, customer model, countries, fulfillment process, and edition requirements that are still being defined. Keep future custom behavior in focused addons under `addons/`; do not modify Odoo core files.
