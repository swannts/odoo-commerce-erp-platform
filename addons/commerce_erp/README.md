# Commerce ERP Starter

This installable Odoo module groups the standard applications for the initial connected commerce and ERP foundation:

- Website and eCommerce
- Sales
- Inventory
- Purchase with stock integration
- Accounting

The module adds no business rules or custom data yet. Those depend on the product catalog, customer model, countries, fulfillment process, and edition requirements that are still being defined. Keep future custom behavior in this addon or focused addons under `addons/`; do not modify Odoo core files.
