# Commerce Storefront

This addon replaces the blank Odoo homepage with a responsive store landing page. It reads the company name from the current Odoo website and links customers to Odoo's native `/shop` catalog and `/contactus` page. Catalog records, product prices, checkout, sales orders, inventory, and accounting remain in the standard Odoo apps.

The page uses no sample product data, payment provider, tax setup, or brand assets. Those must come from the business owner and the selected country/edition. The visual theme uses local SCSS assets and does not load remote fonts or scripts.
